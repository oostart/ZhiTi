# 移除切线模式，仅保留框选模式

## Summary

删除「切线模式」及其全部相关状态、界面与生成逻辑，切割页只保留框选模式：拖拽框选（可多次、可跨页）→「创建题目」合并成一题，或「追加到第 N 题」。同时清理不再使用的 `regionsFromCuts` 与所有"切线/框选"并列的文案。

## Current State Analysis

- [CutView.vue](file:///e:/Projects/StudySI/src/views/CutView.vue#L35-L47) 顶部状态包含 `mode`、`cuts`、`edgeMarks`、`carryQuestionId`、`carrySourcePage`、`hoverY`，均为切线模式专用（`draftBox`、`pendingBoxes`、`mergeTargetId`、OCR 等为框选/通用状态，保留）。
- [CutView.vue](file:///e:/Projects/StudySI/src/views/CutView.vue#L55-L71) `currentCuts`、`currentEdges`、`currentLineRegions`、`lineQuestionCount`、`carryQuestion`、`carryQuestionNumber` 为切线模式专用 computed。
- [CutView.vue](file:///e:/Projects/StudySI/src/views/CutView.vue#L150-L233) `onPointerDown` 内含切线分支、`onPointerMove` 维护 `hoverY`、以及 `clearCuts`/`removeCut`/`toggleEdge`/`cancelCarry` 均为切线逻辑；框选逻辑（`draftBox`、`pendingBoxes`）与 `removePending`/`clearPending` 保留。
- [CutView.vue](file:///e:/Projects/StudySI/src/views/CutView.vue#L323-L383) `generateFromCuts()` 与跨页 carry 追加逻辑仅服务于切线模式。
- [CutView.vue](file:///e:/Projects/StudySI/src/views/CutView.vue#L405-L413) `removeQuestion` 中对 `carryQuestionId` 的清理、[watch](file:///e:/Projects/StudySI/src/views/CutView.vue#L419-L431) 中对 `edgeMarks`/carry 的重置，均不再需要。
- 模板中：模式切换分段控件、生成按钮、切线渲染（`.cut-line`）、hover 预览、状态栏切线文案、「本页切线」面板（含跨页开关）、跨页待续卡片、提示卡中的切线步骤。
- [pdf.ts](file:///e:/Projects/StudySI/src/utils/pdf.ts#L137-L153) `regionsFromCuts` 仅被 CutView 使用，删除切线模式后成为死代码。
- 其他文案引用：[README.md](file:///e:/Projects/StudySI/README.md#L8)、[SettingsView.vue](file:///e:/Projects/StudySI/src/views/SettingsView.vue#L398)、[ImportView.vue](file:///e:/Projects/StudySI/src/views/ImportView.vue#L124)。
- `.mode-box` 类在当前样式中没有定义，仅作为模板多余 class 存在。

## Proposed Changes

### 1. `src/utils/pdf.ts` — 删除死代码

删除整个 `regionsFromCuts` 函数（[L137-L153](file:///e:/Projects/StudySI/src/utils/pdf.ts#L137-L153)）。`Region` 类型仍被 `extractTextFromRegions` 使用，保留 import。

### 2. `src/views/CutView.vue` — 脚本清理

**imports**：移除 `Eraser` 与 `SquareDashed`；保留 `Scissors`（空态图标仍在用）。移除 `regionsFromCuts` 的导入。

**状态**：删除 `mode`、`cuts`、`edgeMarks`、`carryQuestionId`、`carrySourcePage`、`hoverY`；保留 `draftBox`、`pendingBoxes`、`mergeTargetId`、`generating`、`ocrProgress` 等。

**computed**：删除 `currentCuts`、`currentEdges`、`currentLineRegions`、`lineQuestionCount`、`carryQuestion`、`carryQuestionNumber`；保留 `pendingBoxesOnPage`、`pendingTarget`、`paperQuestions`、`pageQuestions`、`displayWidth`。

**指针事件**：

- `onPointerDown` 删除整个 `if (mode.value === 'line') { ... }` 分支，保留公共守卫后直接进入框选：`dragStart = point; draftBox.value = {...}`。
- `onPointerMove` 删除 `hoverY.value = ...` 赋值，仅保留框选拖拽更新。
- `onPointerUp` 删除 `hoverY.value = null`。

**函数**：删除 `clearCuts`、`removeCut`、`toggleEdge`、`cancelCarry`、`generateFromCuts`；保留 `removePending`、`clearPending`、`appendToQuestion`、`saveRegions`、`createFromPending`、`appendPending`、`buildImage`、OCR 相关函数。

**其他**：

- `removeQuestion` 删除 `carryQuestionId` 分支。
- `watch(ui.activePaperId)` 删除 carry/edge 重置，保留 `mergeTargetId`、`draftBox`、`pendingBoxes` 重置（不再需要遍历 `cuts`/`edgeMarks`）。
- `watch([page, zoom])` 删除 `hoverY.value = null`，仅保留 `void renderPreview()`。

### 3. `src/views/CutView.vue` — 模板清理

- 删除工具栏的 `.segmented` 模式切换块和 `v-if="mode === 'line'"` 的生成按钮。
- 页面容器去掉 `:class="{ 'mode-box': mode === 'box' }"`，仅保留宽度绑定。
- 交互层删除切线渲染 `v-for`/`.cut-line` 与 hover `.cut-preview` 块。
- 状态栏改为单个静态文案：`按住拖动画框可连续圈选多个区域（可跨页），选好后点「创建题目」合成一题；也可追加到已有题目。`
- 删除整段「本页切线」`panel-section`（含标题、清空、跨页开关、提示、切线 chips）。
- 删除跨页待续卡片（`carryQuestion` 卡片）。
- 删除「已切割题目」空态中的"用切线或框选"字样，改为"用框选开始切割吧"。
- 空试卷提示改为"先导入一份 PDF 试卷，再回来进行框选切割。"
- 底部提示卡保留框选三步，删除第 3 条切线说明并替换为：`3. 也可以先在题目列表中选择合并目标，再用「追加到第 N 题」补充内容。`

### 4. `src/views/CutView.vue` — 样式清理

删除切线相关 scoped 样式：`.cut-line`、`.cut-grip`、`.cut-label`、`.cut-preview`、`.cut-chips`、`.edge-toggles`。保留 `.pending-box`、`.pending-label`、`.question-box`、`.cut-stage`、`.cut-statusbar` 等。

## Assumptions & Decisions

- 切线模式完全移除，不做隐藏或开关保留；`regionsFromCuts` 一并删除。
- 框选模式默认即当前唯一模式，无需模式切换按钮；进入切割页即可直接拖拽框选。
- 历史 `.trae/documents` 下的旧计划文档保持原样，不属于应用文案。
- 保留下方「跨页 / 多图题目」提示卡，内容改为纯框选流程。
