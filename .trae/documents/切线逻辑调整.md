# 切线逻辑调整：只切相邻两条切线之间的区域

## Summary

当前切线模式把页面按切线分成 N+1 段（含页面顶部第一条线以上、最后一条线以下的区域）。改为：**只有相邻两条切线之间的区域切成一题，页面顶部与底部（第一条线之上、最后一条线之下）不生成区域、不切题**。即 N 条切线 → N-1 道题，至少需要 2 条切线。

## Current State Analysis

  ```ts
  const points = [0.015, ...sorted, 0.985]
  ```
  然后在 `points` 相邻项之间生成区域，因此 2 条切线会产生 3 个区域（顶部余白、两线之间、底部余白）。

- 仅 `CutView.vue` 使用 `regionsFromCuts`，其他视图（框选模式、导出、题库）不依赖该逻辑，无需改动。

## Proposed Changes

### 1. `src/utils/pdf.ts` — 修改 `regionsFromCuts`

去掉固定上下边界 `0.015 / 0.985`，只遍历相邻切线对：

```ts
/** 根据切割线（归一化 y 值）生成区域：仅相邻两条切线之间算一题 */
export function regionsFromCuts(page: number, cuts: number[]): Region[] {
  const sorted = [...cuts].sort((a, b) => a - b)
  const regions: Region[] = []
  for (let i = 0; i < sorted.length - 1; i++) {
    const top = sorted[i]
    const bottom = sorted[i + 1]
    if (bottom - top < 0.01) continue
    regions.push({ page, x: 0.02, y: top, w: 0.96, h: bottom - top })
  }
  return regions
}
```

保留 `x: 0.02, w: 0.96`（与现有横向留白一致）和 `< 0.01` 的退化段过滤。

- 生成按钮：改为 `:disabled="generating || lineQuestionCount === 0"`，文案改为

- `generateFromCuts()` 空区域提示改为："请先画出至少两条切线，两条切线之间的区域才会切成一题"（原为"至少一条切线"）。
- 状态栏文案改为："在页面上单击可添加一条切线，再次单击已有切线可移除；只有相邻两条切线之间的区域会切成一题，第一条线之上和最后一条线之下的内容不切割。"

不改动切线绘制、删除、清空、框选模式与合并目标逻辑。

## Assumptions & Decisions

- **多线规则**：每相邻两条切线之间的区域各算一题（3 条切线 → 2 题），而不是"首尾两条线之间整体算一题"。
- **单线情况**：只有 1 条切线时无"两线之间"区域，生成按钮禁用并提示至少画 2 条；不生成任何题目。
- **顶部/底部余白被彻底排除**，不做任何裁剪或合并。
- 横向范围保持全宽留白（`x 0.02 / w 0.96`），本次仅调整纵向切分规则。
