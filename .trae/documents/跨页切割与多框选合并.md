# 跨页切割：切线跨页续接 + 框选多次合成一题

## Summary

解决「一道题一半在上一页页尾、一半在下一页页首」的切割问题，提供两条路径：

1. **切线模式跨页**：在当前页勾选「续到下一页」、在下一页勾选「接上一页」，生成时页尾区域与下一页页首区域自动合并为同一题（支持连续跨 3 页以上）。
2. **框选模式多次框选**：不再要求"框一次就建题"，可连续框选多个区域（可跨页、可多次），选好后一次性「创建题目」，所有区域按页码/纵向顺序拼接成一题；也保留「追加到第 N 题」。

- 样式已有可复用的 `.chip`/`.chip.active`、`.card`、`.pending-box`，无需新增结构性组件。

## Proposed Changes

### 1. `src/utils/pdf.ts` — `regionsFromCuts` 增加可选页首页尾

保留"相邻两线之间算一题"的默认行为，新增第三个可选参数，仅在页首/页尾跨页时纳入边缘区域：

```ts
export function regionsFromCuts(
  page: number,
  cuts: number[],
  edges: { top?: boolean; bottom?: boolean } = {}
): Region[] {
  const sorted = [...cuts].sort((a, b) => a - b)
  const regions: Region[] = []
  if (!sorted.length) return regions
  const push = (y: number, h: number) => {
    if (h >= 0.01) regions.push({ page, x: 0.02, y, w: 0.96, h })
  }
  if (edges.top) push(0.015, sorted[0] - 0.015)            // 页面顶部 → 第一条切线
  for (let i = 0; i < sorted.length - 1; i++) push(sorted[i], sorted[i + 1] - sorted[i])
  if (edges.bottom) push(sorted[sorted.length - 1], 0.985 - sorted[sorted.length - 1]) // 最后一条切线 → 页面底部
  return regions
}
```

页面无切线时不返回任何区域；页首页尾区需要至少 1 条切线来界定。

**`generateFromCuts()` 重写**（核心逻辑）：

```ts
async function generateFromCuts() {
  if (!doc.value || !ui.activePaperId) return
  const edges = currentEdges.value
  const regions = currentLineRegions.value
  if (!regions.length) {
    toast('请先画出至少两条切线，或在页首页尾勾选跨页续接', 'warning')
    return
  }
  generating.value = true
  mergeTargetId.value = null
  const previousCarry = carryQuestionId.value
  const previousPage = carrySourcePage.value
  carryQuestionId.value = null
  carrySourcePage.value = null
  let start = 0
  let created = 0
  let continued = false
  try {
    // 页首：若上一页有同页序的跨页题，把页首区域并入
    if (edges.top) {
      const target = previousCarry && previousPage === page.value - 1
        ? paperQuestions.value.find((q) => q.id === previousCarry)
        : null
      if (target) {
        await appendToQuestion(target, [regions[0]])
        continued = true
        start = 1
      } else {
        toast('上一页没有可续接的跨页题目，本页首区域将单独成题', 'warning', 2600)
      }
    } else if (previousCarry) {
      toast('上一页的跨页题目未接续，已保持为独立题目', 'warning', 2600)
    }

    const last = regions.length - 1
    for (let i = start; i < regions.length; i++) {
      const question = await saveRegions([regions[i]], false, true)
      if (question) created += 1
      if (edges.bottom && i === last && question) {
        carryQuestionId.value = question.id
        carrySourcePage.value = page.value
      }
    }
    // 本页只有页首区域且全部并入上一题，同时标记了「续到下一页」：跨页题继续沿用
    if (edges.bottom && start === regions.length && previousCarry && previousPage === page.value - 1) {
      carryQuestionId.value = previousCarry
      carrySourcePage.value = page.value
    }

    cuts[page.value] = []
    delete edgeMarks[page.value]
    const parts: string[] = []
    if (created) parts.push(`新建 ${created} 题`)
    if (continued) parts.push('页首区域已并入上一页跨页题')
    if (carryQuestionId.value) parts.push('页尾区域已标记为跨页待续')
    toast(`本页处理完成：${parts.join('，')}`, 'success')
  } catch (error) {
    toast('切割失败：' + ((error as Error).message || '未知错误'), 'error')
  } finally {
    generating.value = false
  }
}
```

**边缘标记与清理**：

- `toggleEdge(which: 'top' | 'bottom')`：无切线时直接返回；否则确保 `edgeMarks[page.value]` 存在并取反。
- `removeCut` 删除最后一条切线后 `delete edgeMarks[page.value]`。
- `clearCuts` 同时 `delete edgeMarks[page.value]`（不再清 `pendingBox`）。
- `removeQuestion` 若删除的是 `carryQuestionId` 对应题目，清空 `carryQuestionId` 与 `carrySourcePage`。
- `watch(ui.activePaperId)` 重置 `edgeMarks`、`carryQuestionId`、`carrySourcePage`（与现有切线清空一致）。

## Assumptions & Decisions

- 跨页切线的交互采用**页首/页尾开关**（用户已确认），不做贴边点击。
- 页尾跨页题目**立即生成并出现在列表**（只是标记为待续），下一页页首区域追加到该题后重新拼接图片、重新合并文字层；不是隐藏暂存。
- 同一时间只维护一个跨页待续题（一页页尾最多延续一题）；续接校验 `carrySourcePage === 当前页 - 1`，避免同页误接。
- 页首/页尾区域纳入需要至少 1 条切线界定；0 切线仍不出题。
- 框选待选区域翻页保留、切换试卷重置、切换模式保留；`pendingBoxes` 顺序不影响结果（`buildImage` 会按页码与 y 排序）。
- 本次不改导出、题库、OCR 逻辑。
