# 侧边栏「设置」入口下移，移除底部说明文字

## Summary

把左侧导航中的「设置」从主菜单列表移到侧边栏最下方的红框区域（当前"本地存储 · 数据不出本机"说明文字所在位置），并删除该说明文字及其小标题，让底部区域只保留一个与主菜单风格一致的「设置」入口。

## Current State Analysis

- [App.vue](file:///e:/Projects/StudySI/src/App.vue#L32-L38) 的 `navItems` 把「设置」与导入/切割/题库/导出并列，统一在 [nav 列表](file:///e:/Projects/StudySI/src/App.vue#L134-L146) 中渲染。
- [App.vue](file:///e:/Projects/StudySI/src/App.vue#L148-L153) 的 `.sidebar-footer` 是底部说明区，包含 `Sparkles` 图标标题「本地存储 · 数据不出本机」和一段"试卷与题目保存在本地数据目录…"说明文字（即截图红框内容）。
- [App.vue](file:///e:/Projects/StudySI/src/App.vue#L3) 导入的 `Sparkles` 仅用于该说明区，删除说明后需一并移除。
- [style.css](file:///e:/Projects/StudySI/src/style.css#L173-L181) 的 `.sidebar-footer` 当前按说明文字排版（`font-size: 11px`、`color: var(--text-3)`、`line-height: 1.6`、`padding-left: 12px`），需要改为只承载导航按钮的容器样式。
- 现有 `.nav-item`（[style.css](file:///e:/Projects/StudySI/src/style.css#L123-L171)）已具备完整样式（含 active 状态、badge、hover），底部入口可直接复用，无需新增视觉样式。
- 其他位置未引用该说明文字（`SettingsView.vue` 内有自己的数据目录说明，不受影响）。

## Proposed Changes

### 1. `src/App.vue` — 拆分导航与底部设置入口

- 从 import 中移除 `Sparkles`（`Settings` 保留）。
- `navItems` 删除 `{ key: 'settings', label: '设置', icon: Settings }`，仅保留 `import`、`cut`、`bank`、`export` 四项。
- 将底部 `.sidebar-footer` 内容替换为设置入口：

```html
<div class="sidebar-footer">
  <button
    class="nav-item"
    :class="{ active: ui.view === 'settings' }"
    @click="go('settings')"
  >
    <Settings :size="17" />
    <span>设置</span>
  </button>
</div>
```

- 不新增 badge、不改 `badgeFor`（settings 无角标）。

### 2. `src/style.css` — 调整 `.sidebar-footer` 容器样式

把文字排版样式精简为容器样式（宽度/对齐交给 `.nav-item`）：

```css
.sidebar-footer {
  margin-top: auto;
  border-top: 1px solid var(--border);
  padding-top: 10px;
}
```

删除原 `font-size`、`color`、`line-height`、`padding-left` 属性。

## Assumptions & Decisions

- 「设置」下移到侧边栏底部（红框区域），以分隔线与上方主菜单隔开，交互与视觉复用 `.nav-item`，选中时同样高亮。
- 原红框内的"本地存储 · 数据不出本机"标题与说明文字**全部删除**，不在其他位置补偿提示（设置页已有数据目录说明）。
- 主菜单顺序保持：试卷导入 → 题目切割 → 题库管理 → 题目导出，底部为设置。
